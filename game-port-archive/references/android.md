# Android 规则

2026-11-10 起合集同时收录 PC 和 Android。

## 选包范围

- 按平台分别保留一个最新适用版本。Android优先设备适用ABI（默认arm64-v8a），保留上游APK及必要配套，不以Windows包覆盖Android包，也不下载同平台可替代旧版。Android新版本号不等于Windows更新，两个平台分别判断。
- 仅Xbox/PS5等主机目标仍不下载。此前删除或跳过的Android资源不追溯补齐；2026-11-10 以后的新提交或用户明确要求更新的Android项目按本规则处理。
- 运行包附带的专用生成器/编译器保留；通用SDK、JDK等只写要求。
- 文件夹仍以正式英文游戏名开头，Android可作尾缀。合集现有路径不因增加Android自动改名。

## 核对与说明

- 用APK内ELF核实架构，不能套用PE判断；不在归档过程中安装或执行APK。
- 拆分APK/APKS/XAPK须说明安装器和必需分包，不能假称单APK即装即玩。
- Android说明须列最低系统、ABI、GPU/Vulkan、内存/空间、安装/导入步骤、首次本机生成耗时、用户自备游戏格式及备份边界。
