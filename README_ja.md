# My AI Agent Skills Collection 🚀
これは、私が個人的に作成・メンテナンスしている [Antigravity](https://github.com/GoogleDeepMind/antigravity) (または Claude Code などの Agent ターミナル) 専用のローカルスキル (Skills) コレクションです。
これらのカスタムスキルを作成することで、AI アシスタントに特定領域の専門的な能力を持たせ、通常の対話の限界を突破し、より高度な自動化ワークフローを実現できます。

## 🛠️ 収録スキル一覧
### 1. WeChat公衆号（公式アカウント）記事取得ツール (wechat-article-summarizer)
**概要**:
WeChat公衆号の強力なスクレイピング対策や「環境異常」による CAPTCHA ブロックを回避するために特化して開発された、自動取得スキルです。AI に WeChat の記事を要約させる際、デフォルトのブラウザノードや通常の HTTP リクエストでは CAPTCHA が発動して失敗することが多いため、これを作成しました。
**主な機能**:
- **シームレスな CAPTCHA 回避**: Python スクリプトを使用して標準的なブラウザのリクエストヘッダーを偽装し、ヘッドレスで HTML ソースコードを直接取得。CAPTCHA ポップアップを完全に回避します。
- **高精度な抽出**: 正規表現に基づき、不要な CSS、JS、HTML タグを高精度で除去し、記事のタイトル、著者、および本文のみを抽出します。
- **AI との完全自動連携**: ユーザーが `mp.weixin.qq.com` のリンクを送信したことを Agent が検知すると、シームレスにこのスクリプトを呼び出してプレーンテキストを取得し、高品質な構造化された要約を出力します。
**利用シーン**:
「この記事を要約して：https://mp.weixin.qq.com/s/...」

### 2. Web ページからクリーンな PDF への変換ツール (webpage-to-pdf)
**概要**:
広告、サイドバー、ポップアップなどを含む複雑な Web ページを、電子書籍のようにクリーンな PDF ファイルに変換することに特化したローカルスキルです。
**主な機能**:
- **遅延読み込み (Lazy Loading) の回避**: Playwright を使用して Chromium ブラウザを操作し、人間の自然なスクロール動作をシミュレートすることで、ページ内のすべての「遅延読み込み」画像が完全に読み込まれてからキャプチャを実行します。
- **DOM のスマートな浄化**: 特定の CSS ルールを自動的に注入し、ナビゲーションバー、サイドバー、フローティング広告、フッターの著作権情報などの不要な要素を強制的に非表示にします。
- **レイアウトのリセット**: Web ページ本文の幅制限を自動的に解除 (100% フル幅) し、エクスポートされる A4 サイズの PDF をコンパクトで高解像度かつ美しく仕上げます。
**利用シーン**:
「この Web ページをクリーンな PDF として保存して：https://www...」

### 3. 多言語公式SNS投稿作成ツール (official-social-posts)
**概要**:
公式アカウントの日常投稿を作成するための多言語SNSライティングスキルです。デフォルトでは Twitter/X 向けですが、他のプラットフォームにも応用できます。ブランドの決まりごと（言語、トーン、文字数制限、ハッシュタグのスタイル、禁止ワード、トーンの基準となる実例）をすべて「ブランドプロファイル」ファイルに集約し、生成時は必ずプロファイルを読み込みます。会話の記憶に依存しないため、新しいセッションでも確立したスタイルをそのまま引き継げ、「前回確認した設定が消える」問題を根本から解決します。
**主な機能**:
- **プロファイル駆動**: プロファイルがあれば設定の再確認なしで直接生成。なければ作成モード（既存資料の抽出または数ラウンドのヒアリング）に自動移行。利用中に修正された言い回しはプロファイルに書き戻せます。
- **多言語の一括出力**: 言語ごとに必須の3点セット（そのまま投稿できる本文＋言語別の3〜5個のハッシュタグ＋画像方針）を固定テンプレートで出力。機械翻訳ではなく各言語で独立にローカライズします。
- **実例によるトーン制御**: 良い投稿と悪い投稿の対比例（課題から入る vs 冒頭から商品名）を内蔵。リプライモードでは「価値を足す・売り込まない・リンクを貼らない」を徹底し、宣伝臭い返信事故を防ぎます。
- **納品前セルフチェック**: 文字数はコマンドで実測（目測禁止）、ハッシュタグ数の確認、禁止ワードゼロ、事実の記述には出典必須——全項目クリアしてから納品します。
**利用シーン**:
「現在のAIトレンドをもとに、日本語と英語の公式X投稿とハッシュタグを作って。」

### 4. DX認定申請書クローリング＆セマンティック分析ツール (dx-certification-scraper)
**概要**:
日本IPAの「DX推進ポータル」に登録されている認定事業者の申請書（ZIPファイル）をダウンロード・抽出し、大モデルのセマンティック（意味）理解により、特定条件（AI開発/API導入需要、SaaSビジネス展開、建設業界の近代化など）に合致するターゲット企業を精度高く選別・分析するローカルスキルです。
**主な機能**:
- **2フェーズのインテリジェントパイプライン**: フェーズ1でPythonスクリプトがCSV一覧・ZIP申請書を一括ダウンロードし、Shift-JISのファイル名をデコードしながらdocx本文をJSONに展開。フェーズ2で大モデルが文脈からセマンティック判断を行い、ターゲットに合致するか精査します。
- **柔軟なフィルタリングロジック**: キーワードの一致だけでなく、大モデルの推論に基づいて、企業の真のAI開発状況やSaaS指向を分析し、A/B/Cの確度でレイティングを分類します。
- **Excelレポートの自動作成**: 判定理由、原文の抜粋、営業に向けた分析詳細をまとめたマルチシート形式の美しいExcelファイル（XLSX）を自動で生成・出力します。
**利用シーン**:
「このDX認定ページから、本当にAI APIの需要がある企業を抽出して：https://disclosure.dx-portal.ipa.go.jp/p/dxcp/top?page=1」

### 5. X（Twitter）アカウント分析＆アウトリーチ文案作成ツール (x-outreach)
**概要**:
B2Bコールドアウトリーチ（パートナー募集・顧客転換）向けのライティングスキルです。X（Twitter）アカウントの持ち主の実像を先に調査し、「プロモーションプロファイル（Profile）」の仕組みに基づいて、パーソナライズされた日本語のDMやリプライを生成します。対外的な言い回し、オファーの数字、禁止ワードをすべてプロファイルファイルに蓄積するため、新しいセッションでもコールドスタートでき、「セッションが変わると決めた言い回しが失われる」問題を解決します。
**主な機能**:
- **本人確認の徹底**: SNS垂直検索とWeb情報源をクロスチェックし、相手の本名（正しい漢字表記を含む）、現在の肩書、会社・事業を確認。古い肩書や改名、同音異字の姓による事故を防ぎます。
- **コンプライアンス判定**: 身分別の制約テーブルを内蔵——公務員には紹介報酬を絶対に提示しない（副業禁止規定）、民間の経営者にのみ具体的な数字を提示。炎上・詐欺疑惑などのリスクも検知し、判断はユーザーに委ねてありのまま報告します。
- **プロファイル駆動の生成**: セールスポイントの順序、価格の言い回し、禁止ワード表、署名フォーマットをすべてプロファイルから読み込み。プロファイルがない場合は自動的に作成モード（既存資料の抽出または数ラウンドのヒアリング）に入り、利用中に修正された言い回しはプロファイルに書き戻せます。
- **2つの出力モード**: DMモードは、直近の投稿から抽出した具体的なフックと、答えやすい疑問形CTAを備えた構造化されたメッセージを生成。リプライモードは、宣伝色のない短いコメントを生成し、まず存在感を築きます。
**利用シーン**:
「この人のアカウントを見て：https://x.com/xxx 。提携の相談でDMを送りたい。」
