# My AI Agent Skills Collection 🚀
这里是我个人发起制作，并由 Codex 等 AI Agent 共同参与制作与维护的面向 AI Agent 的本地技能（Skills）汇总合集。
通过编写这些自定义技能，我可以让 AI 助手掌握更多垂直领域的专属能力，突破常规交互的限制，实现更深度的自动化工作流。

## 🛠️ 包含的技能列表
### 1. 微信公众号文章抓取助手 (wechat-article-summarizer)
**简介**：
针对微信公众号极强的反爬虫和“环境异常”人机验证拦截机制，专门开发的一个免验证自动化抓取技能。当遇到需要 AI 总结微信文章时，默认的浏览器子节点或普通的 HTTP 请求常常会触发人机验证导致抓取失败。
**核心功能**：
- **无感绕过验证**：底层通过 Python 脚本及伪装标准浏览器请求头，直接无头获取公众号 HTML 源码，完美绕开“环境异常”的验证弹窗。
- **自动精准提取**：基于正则高精度剥离多余的 CSS、JS 和 HTML 标签，仅保留最核心的文章标题、作者和正文。
- **AI 全自动衔接**：Agent 只要检测到用户发送了 `mp.weixin.qq.com` 的链接，便会无缝调用此脚本获取纯文本，最后自动输出高质量的文章结构化总结。
**使用场景**：
“帮我总结一下这篇文章：https://mp.weixin.qq.com/s/...”
### 2. 网页转纯净版 PDF 助手 (webpage-to-pdf)
**简介**：
一个专门用于将包含广告、侧边栏和弹窗的复杂网页转换成排版干净、如同电子书般纯净的 PDF 文件的本地技能。
**核心功能**：
- **突破懒加载**：使用 Playwright 底层驱动 Chromium 浏览器，模拟真实人类用户的自然下拉滚动行为，确保网页内所有的“懒加载”图片完全加载完毕后再进行抓取。
- **DOM 智能净化**：自动注入特定的 CSS 规则，暴力屏蔽常见的导航栏、侧边栏、悬浮广告、底部版权信息等无关干扰元素。
- **重置排版**：自动释放网页正文的宽度限制（100% 满宽），使最终导出的 A4 尺寸 PDF 版面紧凑、高清且美观。
**使用场景**：
“帮我把这个网页干净地存为PDF：https://www...”

### 3. 多语种官方社媒推文助手 (official-social-posts)
**简介**：
一个用于品牌官方账号日常内容生产的多语种社媒写作技能，默认面向 Twitter/X，也可用于其他平台。所有品牌口径（语种、语气、字数限制、hashtag 风格、禁词、语气范例）沉淀在「品牌档案（Profile）」文件里，产出强制读取档案而不依赖对话记忆——换个会话也能无缝续上以前的风格，从根源上解决「上次确认过的偏好又丢了」的问题。
**核心功能**：
- **档案驱动**：有档案直接产出、零重复提问；无档案自动进入建档模式（抽取现成资料或多轮访谈建立）；使用中被纠正的措辞可回写档案，积累不散失。
- **多语种成套输出**：强制三件套模板（可直接发布的文案 + 每语种独立的 3~5 个 hashtag + 配图方案），各语种按当地语感独立成文而非机翻。
- **语气范例锚定**：内置好/坏推文对比范例（先讲问题再带品牌 vs 开头报菜名），回帖模式专门约束「有增量、不推销、不留链接」，避免公开处刑式的广告回复。
- **交付前自查**：字数用命令实测不目测、hashtag 数量核对、禁词表零命中、事实性表述必须有出处，逐条过完才交付。
**使用场景**：
“基于当前 AI 热点，帮我写一条日英双语官推，并配 hashtag。”

### 4. DX 认定企业申报书抓取与语义分析助手 (dx-certification-scraper)
**简介**：
专门用于抓取和分析日本 IPA DX 推进门户上已认定企业的 DX 申报书（申請書 ZIP 文件）。结合脚本的自动化数据提取能力和大模型的语义理解能力，精准筛选符合特定画像（如：有 AI 建设及 API 接入需求、属于 SaaS 模式开发、属于建筑行业等）的目标企业。
**核心功能**：
- **两阶段智能管线**：第一阶段利用 Python 脚本自动下载 CSV 目录、下载对应的 ZIP 申报书，并对 Shift-JIS 编码 of 日本语文件名进行解码并提取 docx 纯文本至 JSON；第二阶段由大模型在上下文内进行精准的语义过滤和评级。
- **灵活的筛选规则**：摆脱了生硬的静态关键词匹配，完全基于大模型的语义推理。可根据每次任务的要求，动态评估企业真实的 AI 改造进展、SaaS 开发倾向或行业垂直度，并进行 A/B/C 分级。
- **可视化 Excel 报告**：自动编译多 Sheet 的精美 Excel 文件，包含目标画像判定理由、原文关键段落提取以及面向销售的需要预测。
**使用场景**：
“分析这个 DX 门户页面，找出真正有 AI 建设/API 接入需求的企业：https://disclosure.dx-portal.ipa.go.jp/p/dxcp/top?page=1”

### 5. X（推特）账号分析与触达文案助手 (x-outreach)
**简介**：
一个面向 B2B 冷触达（合作伙伴招募、客户转化）的写作技能：先查清 X（推特）账号主的真实身份背景，再基于「宣传档案（Profile）」机制生成个性化的日文 DM 私信或推文回帖。核心解决「换个会话口径就丢失」的问题——所有对外话术、方案数字、红线禁词都沉淀在档案文件里，任何新会话都能冷启动。
**核心功能**：
- **身份深度核实**：通过社媒垂直搜索与网页信源交叉核实，确认对方真名（含正确汉字写法）、当前职位与公司业务，避免旧头衔、改名和同音姓氏翻车。
- **合规约束判定**：内置身份约束表——对方是公务员就绝不提分成（副业禁止）、是民间经营者才给具体数字，并顺带扫描争议风险如实上报，由用户定夺。
- **档案驱动生成**：卖点顺序、价格口径、禁词表、署名格式全部读取档案文件；无档案时自动进入建档模式（抽取现成资料或多轮访谈）；使用中被纠正的措辞可回写档案，积累不散失。
- **双模式输出**：DM 模式产出结构完整的私信（含从最近推文提取的具体钩子和低门槛疑问句 CTA）；回帖模式产出短小、无广告味的公开回复，用于铺垫存在感。
**使用场景**：
“看下这个人的推特 https://x.com/xxx ，我打算给他发 DM，看看他有没有兴趣跟我们合作。”
